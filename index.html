“내가 남긴 네 개의 연구 기록을 순서대로 해독하면 연구실의 잠금장치를 열 수 있다. 일차함수의 그래프를 읽고, 식을 만들고, 두 그래프의 만남을 찾아라.”

🎮 미션 진행 방법

  • 각 스테이지의 일차함수 암호를 해독하여 보안 키(Key 숫자)를 획득하세요.

MISSION 1 : 첫 번째, 쪽지 속 암호 [기울기, y절편, x절편]

📡 시스템 메시지
책상 위에 쪽지가 있다.
"내가 연구하던 데이터를 일차함수 식으로 만들었다. 자네라면 기울기, y절편, x절편을 찾을 수 있겠지?"
일차함수 y = 3x + 6 의 기울기를 a, y절편을 b, x절편을 c라 할 때,
a + b + c 의 값 (Key 1)을 구하시오.
❌ 암호가 일치하지 않습니다. 다시 계산해보세요!
1) 기울기 a = 3
2) y절편 b = 6
3) x절편 c는 y=0일 때 x값이므로 0 = 3x + 6 에서 x = -2입니다.

MISSION 2 : 두 번째, 금고 보안 장치 [손상된 좌표 복원]

📡 책상 아래에 금고가 있고, 보안 장치가 걸려있다.
"좌표평면에 남아있는 두 점 (3, -5)와 (1, -1)을 연결하는 원래의 일차함수 식을 복원하세요."
두 점 (3, -5)와 (1, -1)을 지나는 일차함수의 식을 y = ax + b라 할 때,
a × b 의 값 (Key 2)을 구하시오.
❌ 손상된 데이터 복원 실패! 기울기와 y절편을 다시 확인하세요.
1) 기울기 a = (-5 - -1) / (3 - 1) = -4 / 2 = -2 입니다.
2) 점 (1, -1)을 지나므로 y = -2 x + b 에 대입하면 y절편을 구할 수 있습니다.

MISSION 3 : 세 번째, 연구실 속 다른 방

📡 금고 안의 열쇠를 찾았다. 뒤쪽 문을 열어야겠다.
연구실 뒤쪽 작은방으로 진입했습니다. 벽에 글이 쓰여있네?
"두 개의 방정식의 신호가 교차하는 위치를 찾아 세 번째 키를 해독하세요."
연립방정식 x + y = 5 , x - y = 1 의 해 (a, b)에 대해
a + b 의 값 (Key 3)을 구하시오.
❌ 신호 교차점을 찾지 못했습니다. 연립방정식을 다시 풀어보세요.
연립방정식의 해가 곧 두 일차함수 그래프의 교점입니다.
가감법을 이용하여 두 식을 더하면 2x = 6 에서 x = 3 이고, y = 2 가 나옵니다.

MISSION 4 : 네 번째, 구역의 넓이를 구하라

📡 사람의 목소리가 들린다.
"여기까지 오다니, 훌륭하군. 이제 마지막 문제다."
네 직선 x = -2, y = -1, x = 3, y = 4 로 둘러싸인
직사각형의 넓이 (Key 4)를 구하시오.
❌ 넓이 계산 오류! 가로와 세로의 길이를 다시 확인하세요.
1) 가로 길이: x = 3 에서 x = -2 까지의 거리 = 3 - (-2) = 5
2) 세로 길이: y = 4 에서 y = -1 까지의 거리 = 4 - (-1) = 5
3) 직사각형 넓이 = 가로 길이 × 세로 길이
