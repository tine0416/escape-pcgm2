MISSION 01 핵심 개념: 뜻, 절편, 기울기

[미션 1] 개념 좌표 암호 해독

주어진 일차함수의 식을 분석하여 x절편, y절편, 기울기 값을 구하세요.

다음 일차함수 식에서 각 요소를 찾아 계산하세요

y = -2x + 6

• x절편을 A 라 한다.

• y절편을 B 라 한다.

• 기울기를 C 라 한다.

➔ 질문: A + B + C 의 값은 얼마입니까?

생각의 길잡이:

  • x절편 (A): y = 0 일 때의 x값입니다. 0 = -2x + 6 을 풀어보세요.
  • y절편 (B): x = 0 일 때의 y값 (또는 상수항)입니다.
  • 기울기 (C): x의 계수입니다. (음수 포함!)
  • 🗣️ 모둠원에게 "왜 A, B, C가 그 값이 나오는지" 직접 말로 설명해 보세요!
MISSION 02 핵심 개념: 일차함수의 식 구하기

[미션 2] 두 점을 지나는 직선의 식 복원

파손된 데이터 파일에서 두 점의 좌표가 발견되었습니다. 두 점을 모두 지나는 일차함수의 식을 완성하세요.

두 점을 지나가는 일차함수의 식을 구하세요

지나는 두 점: (1, 1) 과 (3, 5)

구하고자 하는 일차함수 식: y = ax + b

• 기울기 a 와 y절편 b 의 값을 각각 정확히 계산합니다.

➔ 질문: a × b 의 값은 얼마입니까?

생각의 길잡이:

  • 기울기 a 구하기: a = (y의 증가량) / (x의 증가량) = (5 - 1) / (3 - 1) 를 계산합니다.
  • y절편 b 구하기: 구한 기울기 a를 식 y = ax + b 에 넣고, 점 (1, 1) 을 대입하여 b를 구합니다.
  • 최종적으로 a × b 의 곱을 계산하세요! (b가 음수일 수 있습니다)
MISSION 03 핵심 개념: 일차함수와 연립일차방정식

[미션 3] 두 직선의 교점 좌표 해독

두 일차방정식의 그래프가 만나는 **교점의 좌표**는 연립일차방정식의 해와 같습니다. 교점의 위치를 찾아내세요.

두 일차방정식의 그래프 교점 (p, q)를 구하세요

① x + y = 5 ② 2x - y = 1

• 두 그래프의 교점의 좌표를 (p, q) 라 합니다.

➔ 질문: p × q 의 값은 얼마입니까?

생각의 길잡이:

  • 연립방정식 풀기: 두 식 x + y = 5 와 2x - y = 1 을 가감법(더하기)으로 정리해 보세요.
  • (x + y) + (2x - y) = 5 + 1 ➔ 3x = 6 이므로 x = 2 (p값)가 됩니다.
  • x = 2 를 첫 번째 식에 대입하면 y = 3 (q값)이 됩니다.
  • 교점 (2, 3) 에서 두 값 p × q 의 곱을 계산하세요!
MISSION 04 핵심 개념: 네 직선으로 둘러싸인 도형의 넓이

[미션 4] 네 직선으로 둘러싸인 도형의 넓이 해독

좌표평면 상의 4개의 직선의 방정식을 분석하여, 이들로 둘러싸인 사각형의 넓이를 구하세요.

다음 네 직선으로 둘러싸인 사각형의 넓이를 구하세요

x = -2 x = 3 y = -1 y = 4

• x = k 는 y축에 평행한(x축에 수직인) 직선입니다.

• y = k 는 x축에 평행한(y축에 수직인) 직선입니다.

➔ 질문: 네 직선으로 만들어지는 사각형의 넓이는 얼마입니까?

생각의 길잡이:

  • 가로 길이 구하기: 두 직선 x = -2 와 x = 3 사이의 거리를 계산합니다. 3 - (-2) = 5
  • 세로 길이 구하기: 두 직선 y = -1 과 y = 4 사이의 거리를 계산합니다. 4 - (-1) = 5
  • 넓이 구하기: 직사각형의 넓이 = 가로 길이 × 세로 길이 를 계산하세요!
